One complete story in exactly six words:

> He practiced goodbye. She never came.

He rehearsed the farewell for years — the words, the moment, the door.
She never came to hear it. The goodbye stayed practiced, never given.

`main.py` (Python 3, standard library only, no network) writes the story to
`/output/entry.txt`. The run is deterministic: every run produces the exact
same 37 bytes, and the program asserts the story is exactly six words and
inside the bounty gate of 1–60 characters.

## Run it

```sh
python3 main.py
```
